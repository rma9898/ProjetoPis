# 🎮 Web Scraping da Steam — Projeto PIS

> Aplicação de monitoramento e scraping de promoções da Steam desenvolvida para o projeto acadêmico.

---

## 📌 Sobre o Projeto

Este projeto consiste em um sistema de *web scraping* que coleta dados em tempo real sobre jogos e promoções da loja Steam, armazenando as informações em banco de dados e disponibilizando os dados através de uma interface/bot.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem Principal:** Python 3.10+
- **Backend & Scraping:** Playwright / BeautifulSoup / SQLAlchemy
- **Banco de Dados:** PostgreSQL
- **Frontend / Interface:** Python (Telegram Bot / Web)
